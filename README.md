# RegistryLib

A Minecraft mod built with NeoForge.

- **Minecraft**: 26.1-snapshot.11
- **NeoForge**: 26.1
- **Gradle**: 9.0
- **Java**: 25

## Setup

1. Clone the repository
2. Open in your IDE and import as a Gradle project
3. Run `./gradlew build` to build the mod

## Run Configurations

- `./gradlew runClient` - Run the Minecraft client
- `./gradlew runServer` - Run the dedicated server
- `./gradlew runData` - Run data generators
- `./gradlew build` - Build the mod JAR
