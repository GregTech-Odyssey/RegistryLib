# 核心系统

这一组页面解释横跨多个内容类型的系统能力，而不是某一个单独的注册对象。

## 包含内容

- [Group System]({{ '/group-system/' | relative_url }})
- [Tooltip System]({{ '/tooltip-system/' | relative_url }})
- [Lang System]({{ '/lang-system/' | relative_url }})

## 何时先看系统页

- 你已经会注册单个对象，但开始重复写相同默认值。
- 你需要组织更复杂的 tooltip 或多语言输出。
- 你在教程页里看到某个概念反复出现，想一次性理解它的职责边界。
